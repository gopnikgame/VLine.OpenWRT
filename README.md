# VPN-маршрутизация для OpenWrt

Дополнение LuCI подключает устройства локальной сети к VPN через Xray. Можно добавить свою HTTPS-подписку, проверить серверы по HTTP HEAD, выбрать активный сервер и настроить резервное подключение. Поддерживаются VLESS с TLS или REALITY и Hysteria2 с TLS. Для подключения нужен публичный IPv4 сервера.

[Исходный репозиторий](https://github.com/gopnikgame/VLine.OpenWRT) · [Лицензия](LICENSE) · [Полная инструкция по установке](install/README.md)

## Совместимость

На роутере нужны LuCI, uhttpd и поддержка TPROXY в ядре. Сначала выполните `ubus call system board` и сверяйте выпуск, целевую платформу и архитектуру. Устанавливайте на чистый OpenWrt или после отключения и удаления предыдущей редакции. Выпуски используют общие порты и таблицы маршрутизации.

| OpenWrt | Роутер или платформа | Пакет |
| --- | --- | --- |
| 24.10.8 | `x86/64` | IPK, `x86_64` |
| 24.10.8 | `mediatek/mt7622`, включая Redmi AX6S | IPK, `aarch64_cortex-a53` |
| 24.10.5 | Cudy WBR3000UAX v1 с ревизией `r29087-d9c5716d1d` и указанным ABI ядра | IPK, `aarch64_cortex-a53`. Для штатного объёма флеш-памяти нужен USB extroot. |
| 25.12 | `x86/64` | APK, `x86_64` |

Перехват рассчитан на IPv4-трафик выбранной LAN. Перед первым подключением проверьте, что flow offload выключен и на роутере отсутствует IPv6-маршрут по умолчанию. DNS самого роутера настраивается отдельно. [Условия перехвата и рабочие проверки](luci/README.md#рабочее-подключение)

## Установка

### OpenWrt 24.10 с opkg

На компьютере с Python 3.9+ клонируйте этот репозиторий и соберите комплект. Пакет LuCI используется вместе с runtime. Сборщик загрузит закреплённые версии зависимостей и сверит их SHA-256.

```sh
git clone https://github.com/gopnikgame/VLine.OpenWRT.git
cd VLine.OpenWRT
mkdir -p build
python3 luci/build-ipk.py build
python3 install/build-bundle.py build/luci-app-vpn-routing_0.3.12-1_all.ipk build/vpn-routing-bundle --arch x86_64
```

Для AX6S и совместимой сборки Cudy укажите `--arch aarch64_cortex-a53`. Каталог `build/vpn-routing-bundle` до сборки должен отсутствовать. Сохраните SHA-256 манифеста, напечатанный сборщиком, и скопируйте комплект на роутер в `/tmp/vpn-routing-bundle`.

На роутере выполните от root, подставив SHA-256 манифеста. `--check` проверяет платформу, контрольные суммы, свободное место и план установки. `--install` сохраняет резервную копию настроек и устанавливает пакеты. Скопируйте резервную копию с роутера до перезагрузки.

```sh
cd /tmp/vpn-routing-bundle
sh install.sh --check SHA256_МАНИФЕСТА
sh install.sh --install SHA256_МАНИФЕСТА
```

### OpenWrt 25.12 с apk

Сборка выполняется на Linux с хостовым `apk` из SDK или ImageBuilder OpenWrt 25.12 для x86/64. Понадобятся оба пакета из комплекта и `check-inactive.sh`. Сверьте контрольные суммы, установите системные зависимости из репозитория своей сборки OpenWrt и выполняйте установку по инструкции. [Команды сборки, проверки подписи и установки APK](install/README.md#openwrt-2512--apk-для-x8664)

## Первое подключение

1. Откройте **Сеть → VPN-маршрутизация → Подключение**. Вставьте ссылку подписки, нажмите **Получить серверы** и подтвердите домен своего поставщика.
2. Выберите сервер и нажмите **Проверить выбранный**. Для сравнения узлов есть кнопка **Проверить все**. Если подписка передаёт правила Happ или INCY, они появятся в поле **Правила маршрутизации**. Единственный формат выбран автоматически; при нескольких выберите один. **Подключить** загружает, проверяет и сохраняет правила вместе с выбранным подключением.
3. Проверьте выход в интернет с устройства в выбранной LAN. Чтобы ограничить перехват, отключите VPN, откройте **Настройки** и выберите **Только выбранные устройства**. Добавьте устройства из DHCP или укажите IPv4 вручную.
4. При необходимости откройте **Резерв VLESS** и сохраните отдельную ссылку `vless://`. Для смены узла выберите другую строку и нажмите **Подключить**. После перезагрузки программа восстанавливает последнее активное подключение. Кнопка **Отключить** отменяет восстановление и возвращает обычную маршрутизацию.

При отказе туннеля защита блокирует прямой выход перехваченного IPv4-трафика. Маршруты `DIRECT`, которые вы явно задали в профиле, используют обычный выход роутера при рабочем подключении. Проверяйте доступность и внешний IP из выбранной LAN после изменения правил.

## Правила, DNS и обновление подписки

- **Маршрутизация из подписки.** Программа получает предложения правил из того же HTTPS-ответа, что и серверы: `routing: happ://routing/…` или `autorouting: incy://autorouting/…`, а также соответствующие строки в теле подписки. Адрес INCY JSON берётся из подписки пользователя. Выбранный формат привязывается к этой подписке и обновляется вместе с ней. Во вкладке **Настройки → Маршрутизация** видны происхождение профиля, применение и группы `DIRECT`, `VPN`, `BLOCK`. При ошибке загрузки, проверки DAT или применения сохраняются прежние правила. [Форматы, выбор и ограничения](docs/subscription-routing.md)
- **Дополнительный ручной импорт.** Во вкладке **Настройки** откройте **Ручной импорт Happ или INCY**. Сохранённые вручную правила имеют приоритет до явного выбора правил подписки. Чтобы отключить её правила, выберите **Весь трафик через VPN** перед подключением. [Формат правил и геоданные](docs/routing-adapter.md)
- **Локальный DNS.** По умолчанию используется текущая настройка OpenWrt. В LuCI можно выбрать предустановленный профиль или указать свой DNS, включая DoH, DoT и DoQ. Проверьте адрес перед применением и повторите запрос после него. [Поддерживаемые режимы DNS](luci/README.md#локальный-dns)
- **Подписка.** Каждые 6 часов фоновая служба обновляет список, ключи текущего сервера и выбранные правила подписки. Проверенное изменение правил применяется и при неизменной ссылке сервера. После перезагрузки используются сохранённые сервер, правила и DAT; загрузка профиля для восстановления не требуется. HWID создаётся на устройстве и передаётся только источнику подписки. Ссылки подписок и резервные копии настроек храните в закрытом доступе. [Подписки и жизненный цикл соединения](luci/README.md)

Перед обновлением пакетов или удалением отключите VPN в LuCI. Сохраните архив `sysupgrade -b` и отдельную копию `/etc/vpn-routing`. Используйте пакетный менеджер своего выпуска. [Установка и откат](install/README.md)
